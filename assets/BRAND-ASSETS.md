# Third-party brand assets

Logos of other organisations that ship with the app: where each file came from
and what its owner allows. Add a row when you add a logo.

| File                  | Owner            | Source                                                                  | Allowed use                                                                                                                                                                                                                                                            |
| --------------------- | ---------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vatsim-wordmark.svg` | VATSIM           | Public logo pack at `vats.im/logo`, brand guide v2.1 at `vats.im/brand` | The wordmark without tagline may be used in web assets. Do not recolour, stretch, rotate it, or remove the ® or the radar blips. Leave clear space equal to the height of the "I". The round "V" icon is not in the public pack; ask vpmkt@vatsim.net before using it. |
| `discord-symbol.svg`  | Discord          | `discord.com/branding`, Symbol in Blurple                               | May be used to show that we have a Discord server. No edits or recolouring. Only show the symbol with the word "Discord" next to it.                                                                                                                                   |
| `kofi-logomark.png`   | Ko-fi            | Button image from `storage.ko-fi.com/cdn/logomarkLogo.png`              | Creators may use the logo and cup to link to their own page (Ko-fi help centre).                                                                                                                                                                                       |
| `gateway-logo.svg`    | Laminar Research | X-Plane Scenery Gateway                                                 | Marks the Gateway link.                                                                                                                                                                                                                                                |
| `SimBrief-logo.png`   | Navigraph        | SimBrief                                                                | Marks the SimBrief integration.                                                                                                                                                                                                                                        |
| `navigraph-small.png` | Navigraph        | Navigraph                                                               | Marks the navdata source.                                                                                                                                                                                                                                              |
| `xpnavdata-icon.png`  | XPNavData        | XPNavData                                                               | Marks the navdata source.                                                                                                                                                                                                                                              |

Left out on purpose: IVAO wants a minimum width of 80 px and written permission
from pr@ivao.aero; Valve forbids prominent use of the Steam logo and reserves
approval; the map data providers ask for text attribution, not logos.
