# Bundled detection data

## liveryPatterns.json

Texture and object patterns used to recognise which aircraft a livery archive
belongs to, plus the `.acf` identifiers that locate that aircraft once it is
installed.

Source: [XFast-Manager](https://github.com/CCA3370/XFast-Manager), `data/livery_patterns.json`.

Keep the field names as they appear upstream so the file can be refreshed by
copying a newer revision over it.
